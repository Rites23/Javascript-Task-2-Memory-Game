# 🧠 JavaScript Task 2 – Memory Game

A clean and simple memory matching game built using HTML, CSS, and JavaScript.

👉 [**Play the Game Live**](https://rites23.github.io/Javascript-Task-2-Memory-Game/)

## 🎮 How to Play
- Click on two cards to flip them.
- Match all 8 pairs to win.
- If cards don’t match, they flip back after 1 second.
- Game ends when all cards are matched.

## 🚀 Features
- 4x4 grid memory game
- Smooth card flip logic
- Clean UI, no extra sounds or distractions

> Challenge yourself to complete it as fast as possible!
